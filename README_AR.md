# كتاب Deutsch A1 التفاعلي – مشروع Android

هذا مشروع مصدر جاهز للمتابعة والبناء كتطبيق Android باستخدام Capacitor وThree.js.

## المتطلبات
- Node.js 20 أو أحدث
- Android Studio مع Android SDK
- Java 17 أو أحدث

## بناء نسخة Android
1. افتح هذا المجلد في الطرفية.
2. نفّذ: `npm install`
3. نفّذ: `npm run build`
4. نفّذ: `npx cap add android`
5. نفّذ: `npx cap sync android`
6. نفّذ: `npx cap open android`
7. في Android Studio اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

مكان APK بعد نجاح البناء غالباً:
`android/app/build/outputs/apk/debug/app-debug.apk`

## ما تم تجهيزه في هذه النسخة
- دمج مكتبة Three.js محلياً عبر npm بدل الاعتماد على CDN الخاص بها.
- حذف تحميل الخطوط الخارجية حتى لا يتوقف العرض بسببها دون إنترنت.
- إضافة نطق ألماني للكلمات باستخدام Speech Synthesis المتاح في WebView/Android.
- حفظ تقدم التفاعل في تخزين الجهاز المحلي.
- الإبقاء على الدروس التسعة والمشهد ثلاثي الأبعاد والاختبارات.

## ملاحظات
- هذه ملفات مشروع المصدر وليست ملف APK مبنياً بعد.
- أول تثبيت للحزم يحتاج اتصال إنترنت. بعد البناء، ملفات Three.js وواجهة التطبيق مضمّنة محلياً.
- جودة الصوت الألماني تعتمد على أصوات TTS المثبتة في جهاز Android.

## بناء APK تلقائياً عبر GitHub (بدون تثبيت Android Studio على هاتفك)
1. أنشئ مستودعاً جديداً على GitHub من المتصفح أو الكمبيوتر.
2. ارفع محتويات هذا المجلد إلى المستودع، مع مجلد `.github` المخفي.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم **Run workflow**.
5. بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `deutsch-a1-debug-apk`، فك ضغطه، ثم افتح `app-debug.apk` على هاتف Android واسمح بالتثبيت من هذا المصدر عند الطلب.

إذا فشل البناء، افتح سجل الخطأ في Actions وشاركه هنا لأصلحه معك.
